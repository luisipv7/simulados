Veja o código completo do Garçom Digital. Cada passo tem uma explicação simples e a analogia do restaurante para você lembrar o que está acontecendo!

1
Chamar o Garçom — o comando fetch()
🧑‍🍳 No restaurante: você levanta a mão e chama o garçom, dizendo o que você quer.
No código: o JavaScript usa fetch() e passa o endereço da cozinha (a URL da API).
javascript 
// Passo 1: Chamar o garçom
fetch('http://127.0.0.1:8000/usuarios')
💡 O que é a URL? É o endereço da cozinha (o servidor). Assim como um restaurante tem um endereço, a API tem uma URL.
2
Pedir a comida no formato certo — .then(resposta)
🍱 No restaurante: o garçom volta com a bandeja e você pede para ele colocar no prato certo.
No código: o .then() pega a resposta do servidor e converte para JSON (o formato que o JavaScript entende).
javascript
fetch('http://127.0.0.1:8000/usuarios')
  .then(resposta => resposta.json())
💡 O que é JSON? É um formato de texto organizado que o JavaScript consegue ler facilmente. É como a "bandeja padronizada" do restaurante.
3
Colocar a comida na mesa — mostrar na tela
🍽️ No restaurante: o garçom finalmente coloca a comida na sua mesa e você pode comer!
No código: o segundo .then() pega os dados JSON e exibe na tela.
javascript
fetch('http://127.0.0.1:8000/usuarios')
  .then(resposta => resposta.json())
  .then(dados => {
      document.getElementById("texto-da-tela")
        .innerText = dados.nome;
  });
💡 getElementById encontra um elemento na tela pelo ID e innerText coloca o texto dentro dele. É como etiquetar a mesa e colocar o prato lá!

💻 O Código Completo do Garçom

javascript · garcom-digital.js
// 🧑‍🍳 Passo 1: Chamar o garçom (fetch) e dizer o endereço da cozinha
fetch('http://127.0.0.1:8000/usuarios')

  // 🍱 Passo 2: Pedir a comida no formato JSON
  .then(resposta => resposta.json())

  // 🍽️ Passo 3: Colocar a comida na mesa (na tela)
  .then(dados => {
      document.getElementById("texto-da-tela")
        .innerText = dados.nome;
  });
