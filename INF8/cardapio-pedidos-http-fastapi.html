📋 O Cardápio de Pedidos

Métodos HTTP + Rotas FastAPI — A Analogia do Restaurante

👨‍🏫

No restaurante, existem 4 tipos de pedido que você pode fazer:
Pedir para VER o cardápio, FAZER um novo pedido, TROCAR um pedido ou CANCELAR.

Na internet, esses 4 tipos de pedido se chamam GET, POST, PUT e DELETE!

🍽️ Os 4 Tipos de Pedido do Restaurante Digital

👀
GET
Pedir para VER
🧾 Você pede o garçom para trazer o cardápio para olhar. Não muda nada.
🆕
POST
FAZER novo pedido
➕ Você faz um pedido novo. Vai uma informação para a cozinha que ainda não existia.
✏️
PUT
TROCAR o pedido
🔄 Você pediu pizza mas quer trocar por macarrão. Atualiza algo que já existe.
❌
DELETE
CANCELAR o pedido
🗑️ Você desiste e pede para o garçom cancelar. Remove do sistema.

⚙️ Como o FastAPI recebe esses pedidos?

O FastAPI é a cozinha. Cada pedido (método HTTP) chega em uma rota específica — como um balcão diferente para cada tipo de pedido:

GET
@app.get("/usuarios")
Retorna a lista de todos os usuários. É só olhar — não muda nada!
POST
@app.post("/usuarios")
Cria um novo usuário no banco. É um pedido novo!
PUT
@app.put("/usuarios/1")
Atualiza o usuário de ID=1. É uma troca — o dado já existia.
DELETE
@app.delete("/usuarios/1")
Remove o usuário de ID=1. É um cancelamento.
