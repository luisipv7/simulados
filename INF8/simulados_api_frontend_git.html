Bloco 1: Backend, API REST e Autenticação

1. Analise o seguinte código em FastAPI:

@app.post("/produtos/")
def criar_produto(produto: Produto):
    return produto

No contexto do padrão REST (CRUD), que operação e método HTTP este endpoint representa?

2. Considere o trecho abaixo, comummente usado no FastAPI para configurações de segurança:

oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")

Qual é o papel deste código na infraestrutura da sua API?

3. Durante o desenvolvimento, o backend e o frontend frequentemente correm em portos diferentes (ex: localhost:8000 e localhost:3000). Para permitir esta comunicação, usamos no FastAPI:

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    ...
)

O que acontece se nos esquecermos de adicionar esta configuração de CORS?

Bloco 2: Integração Frontend e Fetch API

  body: JSON.stringify(novoUsuario)

Qual é a finalidade exata da função JSON.stringify(novoUsuario)?
