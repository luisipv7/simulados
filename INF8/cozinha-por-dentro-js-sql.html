SQL · Comando
SELECT

📋 É o pedido ao garçom. Diz o que você quer ver. * significa "tudo".

SELECT * FROM usuarios;
🎯
SQL · Filtro
WHERE

🗺️ É a mesa específica. "Não quero ver todos, só os da cidade Norte!"

SELECT * FROM usuarios
WHERE cidade = 'Norte';
🔗
SQL · União
JOIN

🍱 É a bandeja completa. Une duas tabelas — mostra o nome do usuário E o nome do plano dele juntos.

SELECT u.nome, p.nome
FROM usuarios u
JOIN planos p
ON u.id_plano = p.id;
