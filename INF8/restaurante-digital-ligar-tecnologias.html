🍽️ O Restaurante Digital

O caminho completo da informação — Tela até o Banco de Dados

👨‍🏫

Olá! Na aula passada aprendemos que o JavaScript (fetch) é o garçom.

Hoje vamos ver o caminho completo — desde você sentar na mesa até o prato chegar. Tem 5 partes nesse caminho. Vamos conhecer cada uma!

🗺️ O Caminho Completo da Informação

💻
Tela (Frontend)
HTML + CSS + JavaScript

🪑 Você sentado na mesa olhando o cardápio. Você clica em um botão — é como chamar o garçom.

🏃
JavaScript / Fetch
Requisição HTTP

🧑‍🍳 O garçom que anota o pedido e corre até a cozinha. O fetch envia uma mensagem para a API com o que você quer.

⚙️
FastAPI (Python)
Servidor / Backend

👨‍🍳 O cozinheiro. Ele recebe o pedido, verifica se está certo e vai buscar os ingredientes na despensa.

🗄️
PostgreSQL
Banco de Dados

🏪 A despensa / estoque. É onde todos os ingredientes (dados) ficam guardados com segurança. O cozinheiro vai até lá buscar o que precisa.

📦
JSON
Formato da Resposta

🍱 A bandeja com o prato pronto. O cozinheiro coloca a comida na bandeja (JSON) e o garçom traz de volta para você na mesa (tela).

📋 FUNÇÃO NO SISTEMA
A

É a Despensa, o Banco de Dados que guarda todas as informações com segurança.

B

É o Mensageiro (garçom), que leva o pedido da tela até o servidor.

C

É o formato da Resposta (a bandeja), como os dados viajam pela internet.

D

É a Cozinha, que recebe o pedido, processa as regras e busca os dados.
