🗝️ AS CHAVES MÁGICAS

🏅Chave Primária (PK) — O CPF do registro. Cada linha tem um ID único. Nunca se repete!
🔗Chave Estrangeira (FK) — O código de item que aponta para outro baú. Em vez de escrever o nome do Rei, usamos o ID dele!
📋Coluna regular — O atributo do registro (nome, valor, data).

As Chaves Estrangeiras são como portais mágicos entre os baús. Em vez de copiar o nome do Rei em todas as faturas, apenas guardamos o ID do Rei (ex: 1). O servidor busca o nome sozinho quando precisar!

🔗 MAPA DE RELAÇÕES DO COFRE

faturas.id_cliente → clientes.id_cliente A fatura sabe quem é o aliado sem repetir o nome!
faturas.id_servico → servicos.id_servico A fatura sabe qual feitiço foi usado!
pagamentos.id_fatura → faturas.id_fatura O pagamento sabe qual missão foi quitada!

💡 EXEMPLO REAL NO SERVIDOR

CLIENTES

id_cliente: 1
nome_heroi: Rei Artur
reino: Norte

FATURAS

id_fatura: 1
id_cliente: 1 ← FK!
id_servico: 3 ← FK!
ouro_cobrado: 20000

⚡ O servidor lê id_cliente = 1 e vai automaticamente buscar "Rei Artur" no Baú 1. Sem copiar nada!

🧠 O QUE VOCÊ APRENDEU

🏅PK (SERIAL PRIMARY KEY) = ID único e automático de cada registro
🔗FK (REFERENCES) = portal mágico para outro baú — sem copiar dados!
💻CREATE TABLE = feitiço de invocação do baú no PostgreSQL
🔢NUMERIC(10,2) = tipo certo para valores em dinheiro
⚡Banco relacional = baús conectados por chaves. Muda um, atualiza tudo!
