Você vai usar a Engenharia de Prompt para chamar uma IA e pedir que ela estime o custo. Mas atenção: um prompt mal escrito vai dar respostas erradas! Engenharia de Prompt = escrever instruções precisas para a IA

📜 O QUE É ENGENHARIA DE PROMPT?

🎭É a arte de escrever instruções precisas para uma IA (como ChatGPT ou Gemini).
🎯Um bom prompt tem: papel + contexto + regras + formato de saída.
⚠️Prompt vago = resposta inútil. Prompt preciso = resposta que resolve o problema!

1 · PAPEL MÁGICO

"Atue como um Arquiteto de Software..." — define o personagem que a IA vai interpretar.

2 · CONTEXTO

O que o app precisa fazer — login, cardápio, agendamento. Sem contexto, a IA chuta!

3 · REGRA DE OURO

A regra contábil: 50 moedas/hora. Sem isso, a IA inventa um preço diferente!

4 · TELA DE SAÍDA

Exige uma tabela com: módulo | horas estimadas | custo. Define o formato da resposta!

📌 Nesta quest você vai construir o prompt perfeito escolhendo a opção certa para cada uma das 4 partes. No final, a IA vai "responder" com a tabela de custos!
