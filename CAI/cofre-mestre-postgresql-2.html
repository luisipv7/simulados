Hoje você aprende os feitiços para inserir dados (INSERT INTO) e buscar dados (SELECT ... FROM ... WHERE)! INSERT = guardar Loot · SELECT = buscar Loot

📥 INSERT INTO

Coloca um item no baú.
INSERT INTO tabela (col) VALUES (val);

🔍 SELECT ... WHERE

Busca itens específicos.
SELECT * FROM tabela WHERE col = val;
